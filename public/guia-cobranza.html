Glosario — Palabras clave

Definiciones de los términos que usaremos en esta guía

Concepto de cobro
Es el "tipo" de pago. Ejemplos: Colegiatura, Inscripción, Papelería. Se define una vez y se reutiliza en varios planes.
Plan de pago
Es una plantilla que agrupa conceptos con sus montos y define cuándo y cuánto cobrar. Ej: "Plan Primaria 2024-2025 · Mensual · $2,500".
Periodicidad
Con qué frecuencia se genera un cobro. Mensual = 12 cobros al año. Único = 1 solo cobro.
Asignación de plan
Es el proceso de aplicar un plan a uno o varios alumnos. Al asignar, el sistema crea automáticamente los cargos correspondientes.
Cargo
Un cobro pendiente que le aparece a un alumno. Puede estar en estado: Pendiente Parcial Pagado Condonado
Beca
Descuento automático asignado al alumno. Si el concepto "aplica beca" y el alumno tiene beca vigente, el sistema descuenta el porcentaje automáticamente.
Recargo por mora
Cargo extra por pagar tarde. Se aplica automáticamente al pasar la fecha límite de pago.
Descuento por pronto pago
Descuento especial por pagar antes de la fecha límite. Se configura en el plan de pago.
Folio de recibo
Número único que identifica cada pago. Formato: R20240115-0001. Úsalo para buscar pagos anteriores.

1. Conceptos de cobro

¿Qué se cobra? — Aquí defines los tipos de pago del colegio

ℹ️
¿Qué es un concepto? Es el nombre del tipo de cobro: Colegiatura, Inscripción, Papelería, Transporte, etc. Solo necesitas crearlo una vez y luego lo reutilizas en todos los planes que quieras.
Dónde encontrarlo
cgescolar.com / conceptos
Menú lateral → Configuración → Conceptos de cobro
📋 Conceptos de cobro
+ Nuevo concepto

Pasos para crear un concepto
1

Haz clic en "Nuevo concepto"

Botón azul en la esquina superior derecha de la pantalla de Conceptos. Se abrirá una ventana emergente con el formulario.

2

Completa el formulario

Llena los campos según el tipo de cobro que vas a crear:

Campo ¿Obligatorio? Qué escribir
Nombre SÍ El nombre del cobro. Ej: Colegiatura Mensual, Inscripción Anual
Tipo SÍ Elige una opción del menú desplegable (ver tabla de tipos abajo)
Descripción No Texto adicional para aclarar el concepto. Ej: Pago mensual de servicios educativos
Aplica beca No Actívalo si quieres que las becas descuenten de este concepto. Solo disponible si el Tipo es Colegiatura.
Aplica recargo No Actívalo si pagos tardíos de este concepto deben generar recargo por mora.
Activo No Déjalo marcado. Si lo desactivas, el concepto no aparecerá en los planes.
3

Tipos de concepto — ¿cuál elegir?

  • 🎓
    Colegiatura
    Cobro principal del colegio. Se repite mes a mes según la periodicidad del plan. Permite aplicar becas. Ej: Colegiatura mensual.
  • 📝
    Inscripción
    Pago único al inicio del ciclo escolar. Ej: Inscripción 2024-2025.
  • 1️⃣
    Cargo Único
    Un cobro que se hace una sola vez, no se repite. Ej: Excursión, Papelería, Uniforme.
  • 🔁
    Cargo Recurrente
    Un cobro que puede repetirse varias veces en el mismo mes. Ej: Comedor diario, Transporte semanal.
4

Haz clic en "Guardar concepto"

El sistema confirmará que se creó correctamente. El concepto ya aparecerá disponible para usarse en planes de pago.

⚠️
Ten en cuenta No se puede eliminar un concepto que ya tiene cargos generados. Si ya no lo necesitas, desactívalo con el botón de prohibido (🚫) rojo en la tabla.
📄

2. Planes de pago

¿Cuánto y cuándo se cobra? — Agrupa conceptos con montos y fechas

ℹ️
¿Qué es un plan de pago? Es una plantilla que dice: "a los alumnos de Primaria, cobrarles $2,500 de colegiatura cada mes entre agosto y junio". Luego asignas ese plan a los alumnos y el sistema genera los cargos automáticamente.
Dónde encontrarlo
cgescolar.com / planes
Menú lateral → Configuración → Planes de pago → Nuevo plan
Pasos para crear un plan
1

Datos generales del plan

La primera sección pide la información básica del plan:

Campo¿Obligatorio?Descripción
Nombre del plan SÍ Ponle un nombre descriptivo. Ej: Plan Primaria 2024-2025
Ciclo escolar SÍ Selecciona a qué ciclo pertenece. Ej: 2024-2025
Nivel educativo SÍ Primaria, Secundaria, Preparatoria, etc.
Periodicidad SÍ ¿Con qué frecuencia se genera el cargo? (ver abajo)
Fecha inicio SÍ Ej: 01/08/2024 — inicio del ciclo
Fecha fin SÍ Ej: 30/06/2025 — fin del ciclo
📅
Opciones de periodicidad
  • Mensual → Un cargo por mes. Agosto a junio = 11 cargos.
  • Bimestral → Un cargo cada 2 meses = 6 cargos aprox.
  • Semestral → Un cargo cada 6 meses = 2 cargos.
  • Anual → Un solo cargo al año.
  • Único → Un cargo puntual, sin repetición.

Guardar el plan

3. Asignación de planes

¿A quién se le cobra? — Aplica el plan a alumnos y genera los cargos

ℹ️
¿Qué hace la asignación? Cuando asignas un plan a un alumno (o grupo), el sistema genera automáticamente todos los cargos. Por ejemplo: si asignas un plan mensual de agosto a junio, se crearán 11 cargos pendientes para ese alumno.
Dónde encontrarlo
cgescolar.com / planes / asignar
Menú lateral → Configuración → Planes de pago → Asignaciones → Asignar nuevo plan
Pasos para asignar un plan
1

Selecciona el plan de pago

En el campo "Plan de pago", busca y selecciona el plan que creaste. Puedes escribir parte del nombre para filtrar.

✅
Al seleccionar el plan, automáticamente aparecen sus conceptos y fechas en el panel derecho.
2

Elige el alcance de la asignación

En el campo "Alcance", selecciona a quién se le aplica el plan:

  • 👤
    Individual — Solo a un alumno específico.
    Aparecerá un campo para buscar al alumno por nombre o matrícula.
  • 👥
    Grupo — A todos los alumnos de un grupo (ej: 1°A).
    Aparecerá un campo para seleccionar el grupo.
  • 🏫
    Nivel — A todos los alumnos de un nivel (ej: toda Primaria).
    Aparecerá un campo para seleccionar el nivel educativo.
3

Revisa las fechas

Las fechas de inicio y fin se llenan automáticamente desde el plan. Si necesitas ajustarlas para este alumno en particular, puedes modificarlas.

⚠️
Las fechas determinan cuántos cargos se generan. Si cambias las fechas, revisa la vista previa de períodos que aparece abajo.
4

Verifica los conceptos a incluir

En el panel derecho verás todos los conceptos del plan con casillas de verificación. Todas vienen marcadas por defecto.

  • ✅
    Dejar marcado = ese concepto SÍ generará cargos al alumno.
  • ☐
    Desmarcar = ese concepto NO se cobrará en esta asignación.
💡
Ejemplo: Si el plan incluye Colegiatura e Inscripción pero el alumno ya pagó la inscripción, desmarca "Inscripción" antes de guardar.
5

Revisa la vista previa de períodos

Justo debajo de los conceptos verás una lista de los meses/períodos que se van a generar. Confirma que son los correctos.

📅 Períodos a generar
Agosto 2024  ·  Septiembre 2024  ·  Octubre 2024  ·  Noviembre 2024  ·  Diciembre 2024  ·  Enero 2025  ·  Febrero 2025  ·  Marzo 2025  ·  Abril 2025  ·  Mayo 2025  ·  Junio 2025
Total: 11 períodos · 2 conceptos = 22 cargos a generar
6

Haz clic en "Guardar asignación"

El sistema procesará la asignación y generará automáticamente todos los cargos. Recibirás una confirmación con el número de cargos creados.

✅
¡Listo! Los cargos ya aparecen en la pantalla de cobros de cada alumno. El cajero puede empezar a recibirlos.
💰

6. Condonaciones

Perdonar o reducir un cargo ya generado — solo para administradores

ℹ️
¿Qué es una condonación? Es el perdón parcial o total de un cargo que ya existe en el sistema. A diferencia de una beca (que se asigna antes), la condonación se aplica sobre un cargo ya generado, por una razón específica que debe quedar registrada.
🔒
Solo administradores Únicamente los usuarios con rol Administrador pueden crear o cancelar condonaciones. El personal de caja puede ver los descuentos aplicados en la pantalla de cobros, pero no puede crearlos.
Diferencia entre beca y condonación
BecaCondonación
¿Cuándo se aplica? Al asignar el plan (antes de los cargos) Sobre un cargo ya generado y existente
¿Quién la autoriza? Administrador Administrador
¿Se puede revertir? Sí, desactivando la beca Sí, cancelando la condonación
¿Requiere motivo? Sí (opcional en algunos casos) Sí, obligatorio (mín. 10 caracteres)
Tipo de descuento Porcentaje sobre el monto Monto fijo elegido por el administrador

💡
Ejemplo práctico
Cargo de $2,500 · Se condona $500 → Saldo pendiente queda en $2,000 con estado Pendiente.

Cómo cancelar una condonación
1

Abre el detalle de la condonación

En el listado de condonaciones, haz clic en el botón "Ver" (ícono ojo 👁️) de la condonación que quieres revertir.

2

Haz clic en "Cancelar condonación"

En la pantalla de detalle, encontrarás el botón rojo "Cancelar condonación" en la parte inferior. Solo aparece si la condonación está Activa.

⚠️
Efecto inmediato Al cancelar, se eliminan todos los descuentos aplicados y los cargos vuelven a mostrar su saldo original. El sistema pedirá confirmación antes de proceder.
ℹ️
Una condonación cancelada queda en el historial con estado Cancelada pero no se elimina. Siempre hay trazabilidad de lo que ocurrió.
🆘

Problemas frecuentes

Soluciones a los errores más comunes

❓
El alumno no tiene cargos pendientes Verifica que se le haya asignado un plan de pago. Ve a Planes → Asignaciones y busca al alumno. Si no aparece, asígnale un plan (ver Sección 3).
❓
No puedo guardar el plan — "Debe agregar al menos un concepto" El plan necesita al menos un concepto con monto. Asegúrate de haber hecho clic en "Agregar concepto" y llenado el campo Monto.
❓
No aparece el concepto en el menú del plan El concepto puede estar desactivado. Ve a Configuración → Conceptos y verifica que tenga el estado Activo.
❓
El cargo dice "pagado" pero el padre dice que no ha pagado Busca el folio de recibo en Caja → Pagos para ver quién registró el pago y cuándo. Puede ser un error de captura; avisa al administrador para anularlo.
❓
El botón "Registrar cobro" no hace nada Verifica que: (1) hayas seleccionado al menos un cargo, (2) hayas elegido la forma de pago, y (3) si elegiste Efectivo, hayas ingresado el monto recibido.
⚠️
¿No encuentras tu problema aquí? Contacta al administrador del sistema o al soporte técnico con el mensaje de error exacto que te mostró la pantalla.
💡

Consejos y buenas prácticas

Recomendaciones para usar el sistema correctamente

  • ✅
    Crea primero los conceptos, luego el plan
    Antes de crear un plan, asegúrate de que todos los conceptos que vas a incluir ya existen en el sistema.
  • 📅
    Revisa siempre la vista previa de períodos antes de asignar
    Confirma que el número de cargos a generar es el esperado. Un plan mensual de agosto a junio debe mostrar 11 períodos.
  • 🧾
    Guarda o entrega el recibo inmediatamente
    El recibo PDF es el comprobante oficial del pago. Entrega una copia al padre de familia o envíasela por WhatsApp.
  • 🔍
    Anota el folio de recibo cuando tengas dudas
    El folio (Ej: R20240815-0042) es tu referencia para buscar cualquier pago en Caja → Pagos.
  • 👤
    Un alumno puede tener varios planes asignados
    Por ejemplo, un plan de colegiatura y un plan de transporte por separado. Ambos generarán cargos independientes.
  • 🚫
    No desactives un concepto que esté en planes activos
    El sistema no te lo permitirá, pero si debes hacerlo, primero finaliza o desactiva los planes que lo usan.
  • 💳
    Para transferencias, siempre anota la referencia bancaria
    El número de referencia es indispensable para verificar el pago ante cualquier aclaración futura.
